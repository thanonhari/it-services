# Session protocol — {{DOMAIN_NAME}}

Keep these five habits on for every serious session.

## 1. Orient first

- Read `AGENTS.md` map + only the paths needed.
- For multi-file or multi-{{ARTIFACT_SINGULAR}} work: explore structure before the first edit.

## 2. Quality gate

- Apply `.grok/rules/quality.md` before final delivery.
- Run the pre-delivery checklist.

## 3. Effort routing

- Mechanical → `{{FAST_MODEL}}`
- Hard / structural → `{{STRONG_MODEL}}`
- See `.grok/rules/model-routing.md`.

## 4. Tools in-window

- Prefer {{PRIMARY_GEN_TOOLS}} before sending the {{OWNER_ROLE}} to {{EXTERNAL_APPS}}.
- See `.grok/rules/media.md`.

## 5. Wiki first

- Search `wiki/` + `CONTEXT.md` before re-asking durable context.
- Write back durable decisions in under 10 bullets.
- Agent memory (if enabled) is extra recall; **wiki stays source of truth**.

## End of session

- Patch wiki if something important was learned.
- Handoff: point at wiki pages, not raw chat logs.

## What we deliberately do not do

- Bulk-commit unrelated dumps (binaries, screenshots, chat exports) with docs.
- Invent connectors or packages that do not exist.
- Push to remote unless the {{OWNER_ROLE}} asks.
